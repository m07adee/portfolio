# Mohammad Adib Armouch — Portfolio

Animated dark-theme portfolio built with **Next.js 15**, **Tailwind CSS v4**, **Framer Motion** and components from **[VengeanceUI](https://github.com/Ashutoshx7/VengeanceUI)**.

- Edit all content in `lib/data.ts`
- Agent skills (via [`npx skills`](https://github.com/vercel-labs/skills)) live in `.claude/skills/`

```bash
npm install
npm run dev
```
